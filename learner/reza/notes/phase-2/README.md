## Roadmap coverage

Learn discovery and semantic triggering, positive and negative conditions, skill contracts, package roles, progressive disclosure, and platform formats. A skill supplies reusable guidance; it does not supply tools or permission by itself.

**Build:** Create recording-lifecycle-auditor, deepstream-pipeline-debugger, and pytest-failure-diagnoser. Each needs all eight required contract elements and at least three realistic evaluation cases. Start from the [recording contract](../../experiments/recording-lifecycle-auditor-contract.md).

**Exit evidence:** Complete a real repository task with at least one skill, explain each skill's narrow responsibility, and demonstrate repeatability across several cases.
