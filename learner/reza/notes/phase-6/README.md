## Roadmap coverage

Separate portable workflow rules from platform adapters. Manage context, retrieval, and memory; resist instructions embedded in untrusted data; evaluate specialized agents, handoffs, shared state, and coordination failures.

**Build:** Run the same skill in Codex and OpenCode using shared cases. Add adapters only for measured differences, compare trigger accuracy and outcomes, and attempt one separately authorized small multi-agent experiment after the baseline works.

**Exit evidence:** Demonstrate one skill in two environments, document platform differences, and justify multi-agent complexity with evaluation evidence. An experiment that rejects extra complexity does not silently satisfy the last criterion.
