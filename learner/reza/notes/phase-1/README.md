## Roadmap coverage

Connect the agent loop, relevant context, instruction authority, prompts, tools, permissions, task specification, and review. The central question is whether observed evidence supports the requested outcome within the authorized scope.

**Build:** Use the reusable task-request template, code-review checklist, and operating-instructions draft. The revised Build scope includes three guided hypothetical reviews. Actual task-renaming execution and learner acceptance reasoning provide separate practical evidence.

**Exit evidence:** Explain agent components without notes; obtain and review a verified bounded result; identify unsafe or insufficiently verified behavior.
