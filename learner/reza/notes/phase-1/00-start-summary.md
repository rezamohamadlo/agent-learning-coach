# Phase 1: Agent foundations — Start Summary

## Starting point

Read this in the first session of Phase 1. There is no previous phase to recap, so this short orientation establishes the starting vocabulary.

- **Goal:** the outcome you want, including how you will recognize success.
- **Model:** the component that interprets context and generates responses or action requests.
- **Agent:** a system that can use a model, instructions, tools, and feedback to work toward a goal.
- **Tool:** a capability for observing or changing something outside the model.
- **Authority:** the boundaries of what the agent is permitted to do.
- **Evidence:** observations that support a conclusion about the actual result.

For example, asking an agent to explain a failing test sets a diagnostic goal. Reading code provides evidence; permission to inspect does not itself authorize a fix.
