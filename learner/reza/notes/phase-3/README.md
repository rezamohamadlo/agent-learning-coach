## Roadmap coverage

Design structured tool inputs and outputs, distinguish read-only and mutating operations, and enforce authorization. Learn MCP host/client/server roles, authentication, secret handling, errors, timeouts, bounded retries, and idempotency.

**Build:** Build a read-only DeepStream configuration inspector and a test-result summarizer. Expose one safe diagnostic through a small MCP server and test invalid inputs and tool failures.

**Exit evidence:** Explain skill versus tool, return structured validated results, and demonstrate appropriate authorization boundaries for mutations.
