## Roadmap coverage

Track state and history, choose tools to answer specific questions, and inspect results in a bounded loop. Add guardrails, output validation, logs or traces, and a clear reason for any handoff.

**Build:** Create a repository diagnostic agent that accepts a failing test or runtime error, searches relevant code, runs permitted checks, and reports an evidenced diagnosis. Under clear authorization, apply a bounded fix and verify the final change.

**Exit evidence:** Complete a diagnose-and-verify loop, make important actions observable, and report failures explicitly.
