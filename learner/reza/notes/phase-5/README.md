## Roadmap coverage

Define task success, select deterministic or model-based graders, evaluate tool selection and arguments, maintain regression cases, and compare quality with latency and cost.

**Build:** Collect 15–30 real-work cases, including normal cases, edge cases, and expected refusals. Create a repeatable command or checklist, record a versioned baseline, and evaluate after material changes.

**Exit evidence:** Quantify a revision's effect, catch an actual regression or unsafe behavior, and preserve comparable results over time.
