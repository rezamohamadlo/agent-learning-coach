Use this plan when resuming learning. The [roadmap](../ROADMAP.md) tracks completion, the [strengths-and-gaps profile](strengths-and-gaps.md) holds evidence, and the queue below selects what to revisit. This plan schedules review; it does not record a passed assessment.

## Review rhythm

These are adjustable planning intervals, not fixed mastery requirements. Start with roughly 5–10 minutes of review within an ordinary session, adjusting to available time.

| When | Review material | Method |
|---|---|---|
| Beginning of an ordinary learning session | One recent completed concept or corrected gap relevant to today's topic | Brief learner-led recall, then compare with the relevant note |
| About one week after demonstrating a topic | Its main distinction and one application | A fresh scenario, not the original quiz |
| About four weeks later, or during a later practical task | An older concept needed in the current work | Apply it to a different domain or artifact |
| First session of each phase | Previous-phase recap and upcoming-phase preview | Read the phase's start summary and discuss unclear connections |
| Last session of each phase | Current-phase end summary, unresolved gaps, and practical evidence | Read the recap, then complete the phase-boundary review |
| Return after a substantial break | Prerequisites for the next incomplete item | Identify what needs refreshing before new material |

Review sessions occur when the learner returns; no automatic reminders or background monitoring are implied. If a checkpoint was missed, review the most relevant gap first rather than scheduling every missed review at once. A single practical check can satisfy overlapping review purposes when its evidence is sufficient.

## How to review

1. Select one concept from the queue, prioritizing an unresolved prerequisite, then a corrected gap, then an older useful concept.
2. For voluntary self-review, close the note and briefly recall the main idea and an example. Reopen the note and compare. Rereading is preparation, not proof of retention.
3. For a coach-led assessment, identify the review scope and use the established read-confirmation gate. Then use exactly three fresh multiple-choice questions in one Validation section: recall, application, and transfer or diagnosis, each with an I don't know choice. Keep answer examples free of the answer key.
4. If a gap appears, clarify it in the topic note and reassess after the learner reads the correction. Same-session correction does not establish delayed retention.
5. Record the actual result and next review checkpoint. Preserve earlier demonstrated evidence even if a later review exposes a new gap.

Do not turn a narrow clarification discussion into an unannounced quiz. A practical build review remains a separately identified activity and uses the actual artifact and execution evidence.

## Recording results

After an actual review, create a dated session report, update relevant evidence in the strengths-and-gaps profile, and update this queue's evidence date, status, and next checkpoint. Link the report in the roadmap when it affects progress.

Use clear outcomes: reviewed with support, independently demonstrated, retained with supporting delayed/transfer evidence, or gap reopened. Reading a summary, scheduling a review, or receiving an explanation does not by itself raise the evidence level. Record whether notes, hints, or answer feedback were available.
