## Main goals

- [ ] Understand the components and execution loop of an AI agent.
- [ ] Distinguish instructions, skills, tools, MCP servers, memory, and agents.
- [ ] Create narrow, reusable, evaluated skills.
- [ ] Build a safe tool-using agent for a real workflow.
- [ ] Measure reliability with repeatable evaluations.
- [ ] Test selected skills across at least two agent environments.

## Phase 1 — Agent foundations

### Learn

- [ ] Explain the agent loop: observe, reason, act, inspect, and repeat or stop.
- [ ] Understand context windows and instruction priority.
- [ ] Distinguish prompts, persistent instructions, and repository instructions.
- [ ] Explain how tools extend a model into an acting system.
- [ ] Understand permissions, sandboxes, approvals, and destructive-action safety.
- [ ] Define task scope, constraints, acceptance criteria, and verification evidence.

### Build

- [ ] Write a reusable task-request template.
- [ ] Write a checklist for reviewing agent-generated work.
- [ ] Draft project-level agent instructions.
- [ ] Complete three bounded tasks with explicit acceptance criteria.

### Exit criteria

- [ ] Describe the main components of an agent without notes.
- [ ] Give an agent a bounded task and obtain a verified result.
- [ ] Identify unsafe or insufficiently verified behavior.

## Phase 2 — Reusable skills

- [ ] Understand skill discovery, triggering, scope, and progressive disclosure.
- [ ] Create one narrow skill with instructions, references, and evaluation cases.
- [ ] Demonstrate the skill on a real task.

## Phase 3 — Tools and MCP

- [ ] Understand structured tool calling and input validation.
- [ ] Distinguish read-only, mutating, and destructive tools.
- [ ] Build and test one safe tool.
- [ ] Understand MCP tools, resources, authentication, and approvals.

## Phase 4 — Single-agent workflow

- [ ] Build one observable agent loop using a real tool.
- [ ] Add state, error handling, guardrails, and verification.
- [ ] Demonstrate a complete diagnose-and-verify workflow.

## Phase 5 — Evaluation and reliability

- [ ] Define task-level success criteria and graders.
- [ ] Build a regression dataset with normal, edge, and refusal cases.
- [ ] Track quality, safety, latency, and cost.

## Phase 6 — Portability and advanced patterns

- [ ] Separate portable workflow content from platform adapters.
- [ ] Test one skill in two agent environments.
- [ ] Study retrieval, memory, prompt injection, and orchestration.
- [ ] Use multiple agents only when evaluation shows measurable value.
